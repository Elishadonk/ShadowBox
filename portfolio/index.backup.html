ShadowBox

Founder & Developer · 2025–Present

Local communication infrastructure built from the application layer down.

ShadowBox is a secure communication platform focused on privacy, reliable networking and real-time communication. The project explores local-first communication, allowing devices to exchange information through local network infrastructure instead of relying on traditional mobile-network connectivity for the communication path.

The work spans application design, identity and contacts, messaging, media communication, voice and video calling, local storage, Android services, networking, native components and packet-level troubleshooting.
